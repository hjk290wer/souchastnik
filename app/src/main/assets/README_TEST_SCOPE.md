# Internet-scope test corpus

This release deliberately excludes generic offline crimes from the candidate set.

## Include

An article is included when at least one of these is true:

1. The post/message/comment/file/link itself can be the prohibited act.
2. Public dissemination through the Internet is an explicit qualifying element.
3. The Internet can be the explicit method of recruitment, inducement, dissemination, or access required by the article.

## Exclude

Do not add a crime merely because online correspondence can be evidence of it. For example, ordinary theft, traffic offences, illegal hunting, ordinary assault, and pollution are not triggered solely by mentioning them online.

## False-positive rule

A trigger should normally contain an action + object/context. Generic nouns such as `армия`, `выборы`, `вирус`, `реклама`, `оружие`, `деньги` are intentionally insufficient by themselves.
